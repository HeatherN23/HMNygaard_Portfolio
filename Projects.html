Just a few of my projects

My Art Gallery

An interactive gallery browser built with vanilla JS, consuming the Met Museum's public API to fetch and display artwork dynamically. For this project we chose an API to search. For this example, the user searches for a given artist, and the API returns several samples of the artist's masterpieces. This is accompanied by the pertinent data for the masterpiece, including, the artist's name, the title of the piece, the date of the piece, and a link to the Metropolitan Museum of Art's page where more details can be found
